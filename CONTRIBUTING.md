# Contributing

DOS is a personal project by Ostap Shtai, source-available under the
[PolyForm Noncommercial License 1.0.0](LICENSE).

- **Bug reports and ideas:** open an issue. Include your OS, terminal, the
  version (`dos-commander --version`) and, if you can, steps to reproduce.
  Never paste API keys, secrets or your `~/.dos/data.db`.
- **Pull requests:** not accepted for now. The author keeps the right to
  relicense the project (for example to offer a commercial licence, see
  [COMMERCIAL.md](COMMERCIAL.md)), which needs every contributor's consent.
  If you have a patch in mind, describe it in an issue first.
